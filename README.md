# سراب — Sarab VM

تطبيق أندرويد يشغّل أنظمة وهمية (ويندوز PE، لينكس، أندرويد x86، وأي ملف ISO) على هاتفك، باستخدام محرك **QEMU** مفتوح المصدر.

## ماذا يحتاج الهاتف؟

- معالج **arm64** (كل الهواتف تقريبًا منذ 2017).
- أندرويد 8 أو أحدث.
- مساحة فارغة: حوالي 300 MB للتطبيق، إضافة إلى حجم ملفات الأنظمة.

## كيف أحصل على ملف APK؟ (بدون كمبيوتر وبدون خبرة)

المشروع يحتوي على بناء تلقائي في GitHub. خوادم GitHub تبني لك ملف APK مجانًا:

1. أنشئ حسابًا مجانيًا في github.com.
2. أنشئ مستودعًا جديدًا (New repository)، مثلًا باسم `SarabVM`.
3. ارفع ملفات المشروع كلها إلى المستودع. تأكد أن مجلد `.github` رُفع أيضًا، فهو الذي يشغّل البناء.
4. افتح تبويب **Actions** في المستودع. ستجد عملية «Build APK» تعمل، وتأخذ حوالي 10 دقائق.
5. عندما تظهر علامة ✓ خضراء، افتح العملية وحمّل **SarabVM-apk** من قسم Artifacts. فك الضغط عن الملف المحمَّل ستجد `SarabVM.apk`.
6. ثبّته على هاتفك. سيطلب منك الهاتف السماح بالتثبيت من مصادر غير معروفة.

لنسخة دائمة في صفحة Releases: أنشئ وسمًا (tag) يبدأ بحرف v، مثل `v1.0.0`.

## البناء على الكمبيوتر (اختياري)

```bash
python3 scripts/fetch_qemu.py      # يحمّل QEMU لأندرويد ويجهزه داخل المشروع
./gradlew assembleDebug            # الناتج: app/build/outputs/apk/debug/app-debug.apk
```

أو افتح المجلد في Android Studio بعد تشغيل السكربت الأول، ثم اضغط Run.

## طريقة الاستخدام

1. اضغط **نظام جديد** واختر النوع (ويندوز / لينكس / أندرويد / أخرى).
2. اختر ملف ISO أو IMG من هاتفك. يُنسخ الملف إلى مساحة التطبيق مرة واحدة.
3. حدد الذاكرة والأنوية وحجم القرص، ثم اضغط **إنشاء وتشغيل**.
4. في شاشة النظام:
   - **لمس مباشر:** المس مكانًا للنقر، واضغط مطوّلًا للزر الأيمن، واسحب بإصبع للسحب، وحرّك إصبعين للتمرير.
   - **لوحة لمس:** حرّك إصبعك لتحريك المؤشر، والمس للنقر.
   - زر **لوحة مفاتيح** يُظهر الكيبورد وصفّ المفاتيح الخاصة (Esc وCtrl وAlt وWin وF1…).
   - زر **الطاقة** فيه خياران: إيقاف آمن (يطلب من النظام إغلاق نفسه) أو إيقاف فوري.
5. اضغط مطولًا على أي نظام في القائمة لتعديله أو حذفه.

## توقعات واقعية للأداء

الهاتف يحاكي معالج كمبيوتر (x86) بالبرمجيات، لذلك:

- **لينكس الخفيف** (مثل Alpine أو Debian بدون واجهة) يعمل بشكل جيد.
- **Windows PE** وأندرويد x86 يعملان، لكن الإقلاع يأخذ دقائق والاستجابة بطيئة.
- **ويندوز 10/11 الكامل** بطيء جدًا وغير عملي.
- أنظمة **aarch64** (لينكس ARM) هي الأسرع، لأنها بنفس معمارية الهاتف.

## هيكل المشروع

```
app/src/main/java/com/sarab/vm/
  core/      منطق بلغة Java فقط (يُختبر على الكمبيوتر): إعدادات النظام، أمر QEMU، عميل شاشة VNC، أوامر التحكم
  data/      حفظ الأنظمة والإعدادات، نسخ ملفات ISO، تجهيز ملفات QEMU
  service/   تشغيل وإيقاف QEMU، والخدمة التي تبقيه يعمل في الخلفية
  display/   شاشة النظام: عرض الصورة، اللمس، لوحة المفاتيح
  ui/        الشاشات: الرئيسية، نظام جديد، الإعدادات
  util/      الألوان والأدوات المشتركة للواجهة
app/src/test/  اختبارات الكود الأساسي
scripts/fetch_qemu.py        يحمّل QEMU من مستودع Termux ويجهزه للتطبيق
scripts/test_fetch_qemu.py   اختبارات السكربت
.github/workflows/build-apk.yml   البناء التلقائي في GitHub
```

### كيف يعمل من الداخل؟

- أندرويد لا يسمح بتشغيل برامج إلا من مجلد مكتبات التطبيق، لذلك تُوضع برامج QEMU هناك بأسماء `libqemu-system-x86_64.so`.
- برامج QEMU مأخوذة جاهزة من حزم [Termux](https://github.com/termux/termux-packages) المبنية لأندرويد. يعيد السكربت تسمية المكتبات التي في أسمائها رقم إصدار (مثل `libz.so.1` تصبح `libz1.so`) ويعدّل البرامج لتستخدم الأسماء الجديدة.
- يعرض QEMU شاشة النظام عبر VNC على `127.0.0.1`، والتطبيق يحتوي عميل VNC خاصًا به.
- الإيقاف الآمن يتم عبر قناة تحكم QEMU (QMP).

## حل المشكلات

| المشكلة | الحل |
|---|---|
| «محرك QEMU غير موجود في هذه النسخة» | بُني التطبيق بدون تشغيل `fetch_qemu.py`. استخدم ملف APK الناتج من GitHub Actions. |
| يتوقف النظام فورًا مع رسالة خطأ | تظهر آخر رسائل QEMU في نافذة الخطأ. وتجد السجل الكامل في ملفات التطبيق داخل مجلد `logs/`. |
| شاشة سوداء طويلة | انتظر، فالإقلاع بطيء خصوصًا لويندوز. جرّب ذاكرة أقل أو أنوية أقل إذا كان الهاتف ضعيفًا. |
| النظام يتوقف عند الخروج من التطبيق | اسمح للتطبيق بالإشعارات وأوقف «تحسين البطارية» له من إعدادات الهاتف. |

## التراخيص

- QEMU مرخص بـ GPL v2. البرامج المضمّنة مأخوذة من حزم Termux، ومصدرها في https://github.com/termux/termux-packages و https://www.qemu.org.
- إذا وزّعت ملف APK لغيرك، فعليك الالتزام بشروط GPL، ومنها إتاحة الكود المصدري.
- ملفات أنظمة التشغيل (مثل ويندوز) لا تأتي مع التطبيق. استخدم فقط نسخًا تملك حق استخدامها.
